# Support

## Product support

For anything about the Dueback service itself — accounts, API keys,
negotiation cases, billing, or a signup that gets stuck — email
**support@dueback.co**.

Support is best-effort during the founding-beta period; there is no SLA.
Most messages get a reply within a couple of business days.

## GitHub issues

Use GitHub issues in this repository only for:

- Bugs in the local stdio wrapper (`server.py`)
- Errors or gaps in this repository's documentation

Please do not open public issues about your own account, cases, or
billing — those need email so nothing private is posted publicly, and
**never paste API keys, tokens, bills, or bank details into an issue**.

## Security reports

Do not use public issues for security problems. Follow
[SECURITY.md](SECURITY.md) instead — private reporting only.
